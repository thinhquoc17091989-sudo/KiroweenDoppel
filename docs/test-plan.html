The whole loop, on a project that is not Doppel

most important
Do

In the browser, press Approve architecture. Then switch to Kiro and watch the hook.

Expect
  • Kiro's hook fires on its own, without you asking.
  • It creates src/rain-forecast.ts and test/rain-forecast.test.ts.
  • It rewrites src/pump-driver.ts, because that one was stale.
  • It leaves the other four files alone.
Then ask Kiro

Type in Kiro's chat: run check_drift. It should answer that there is no drift.

Why this matters

This is the entire product in one action: you approve a picture, an agent writes the code, and a tool proves the two still agree. It has only ever been proven inside Doppel's own repository.

If nothing happens

The approve worked but the hook did not fire. Check that architecture/plant-watering.puml actually changed on disk. If it did, the hook is registered but not triggering, which is the exact failure we hit once before with the hook file format.
