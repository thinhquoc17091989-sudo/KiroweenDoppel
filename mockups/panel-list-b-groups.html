Doppel
Mockup B — fold away what's settled: collapsible groups with a description-coverage meter.

What this one optimises for

  • Approved elements are usually not what you came to review, so that whole group collapses to one line.
  • The thin bar under each header shows how many in that group have a description — a gap you can see without opening anything.
  • Descriptions still show inline, but only for elements that have one, so a bare model stays compact.
  • Best when the model has a clear split between settled and pending work.
