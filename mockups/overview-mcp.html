MCP

What MCP is
An open standard for giving an agent tools it can call. Kiro calls an MCP tool the same way it calls read-file or write-file — so a tool you build becomes part of how Kiro thinks, not something a human runs afterwards and pastes in.

Doppel's own server

check_drift 2 findings

Registering it

// .kiro/settings/mcp.json
{
  "mcpServers": {
    "doppel-drift": {
      "command": "node",
      "args": ["mcp/server.mjs"],
      "autoApprove": ["check_drift",
                      "list_trace"]
    }
  }
}

Build your own, or reuse one?

Build your own here. Last year's grand prize used Context7, a public server for live library docs — useful, but generic. A server that checks your design against your code is the thing a judge remembers, and it is the one tool that makes "keeps it honest" literally true rather than a slogan.
